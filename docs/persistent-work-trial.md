# OpenMaus 本机试用

打开 http://127.0.0.1:19753/。先创建工作范围、创建项目或持续事务，选择“目标助手”，填写事项名称、要求、成果文件名和执行次数上限，然后提交。页面每 5 秒刷新，事项完成后点击“查看成果”下载已复核文件。

试用服务运行在本机回环地址；数据保存在本仓库 `.persistent-work-trial`，与原有 OpenMausBot 数据分开，不覆盖现有配置。该目录包含独立的登录凭据副本和试用对话，不要分享或加入版本控制。

电脑重启后运行 [启动本机试用.cmd](../scripts/启动本机试用.cmd) 恢复服务。首次启动从当前 Windows 用户的 Codex 登录状态创建独立凭据副本；试用账户若过期，需要在本机重新登录并更新试用凭据。

当前可试用单次文件型事项，包括项目下事项和持续事务下单次事项、执行预算、成果自动检查与负责人复核。持续事务的周期自动生成、Goal 级最终汇总和交付、自动返工以及跨工作范围的完整上下文隔离尚未完成，试用版不作为正式发布。

也可从首页进入“聊天界面（新入口试用）”。选中助手后，在原有聊天输入框写下要求，点击“交办为任务”；普通发送仍用于聊天。任务暂归入“未分类”，输入框附近可查看和设置执行上限。完成后在任务列表点击“查看报告”，在右侧直接阅读文本成果，也可下载。此入口暂不支持附件或自动判断任务意图，报告不会自动带入后续对话。

在本机试用中，直接访问 `/index.html` 也会进入新入口。宽屏显示左侧机器人导航、中间对话、右侧任务与成果；窄屏在对话上方展示任务，报告以侧边抽屉打开。其他 OpenMausBot 环境不会因试用入口自动跳转。

当前主控可在普通聊天中检查已有助手，并按需要创建专业助手；系统会要求它优先复用合适的现有助手，并阻止同部门同名创建。相似职责判断由模型完成，不能保证完全避免语义重复。新助手沿用主控已连接的应用以及工作区默认访问级别，其后执行任务时仍受现有权限规则约束。创建助手本身不等于任务已完成。

## 登录后自动启动

本机可使用当前 Windows 用户的任务计划 `OpenMausBot-Personal-Trial`，登录后隐藏运行 `scripts/watch-persistent-work-trial.ps1`。守护程序检查本机健康接口，在服务未运行时调用原启动脚本；若端口已有响应但后端不健康，则记录情况，不结束未知进程。工作目录、Node 和当前用户 Codex 登录状态需要保持可用。电脑关机、睡眠或用户未登录时不提供服务。

日志保存在已忽略的 `.persistent-work-trial/watchdog.log`、`launcher.log`、`launcher-error.log` 和 `server.log`。停止自动启动可在 Windows 任务计划程序中禁用 `OpenMausBot-Personal-Trial`；禁用后应另外停止当前运行的守护程序和服务。此功能不会自动删除机器人或试用数据。
