# 持久目标运行时接线三阶复盘

1. 结果：隔离实例接通目标创建、原生规划线程、协调器和按真实运行身份授权的目标工具；构建、独立包冒烟、幂等和权限验证通过；复核工具能读取本次授权成果并拒绝篡改。正式个人实例未启用，真实模型完整交付尚待验收。
2. 原因：客户端根任务和普通人工启动根任务原本共用首轮状态投影，实际规划任务被误判为 source，宿主因此取消启动。根据已持久化的客户端根身份区分投影，并补充运行状态回归测试。
3. 可复用改进：接入真实宿主时应同时验证队列状态、执行中投影和工具能力传递；每个新入口先在临时数据目录验证身份、重试幂等及故障恢复。当前方案仍处测试阶段，不提炼为通用 skill。

补充：真实模型诊断发现测试误用了 Windows 的 `.cmd` 包装器，底层同步启动抛错被吞，造成任务永久显示运行中；已补充失败事件与专项测试，并改用实际可执行文件。独立测试环境默认清除代理导致连接超时，真实模型测试现在显式使用本机代理且不记录代理值。真实模型已提交结构化计划、生成实际文件、通过自动检查，并由负责人读取文件复核通过。最初把无法观察的“是否使用网络”写入验收条件时，负责人正确返回 unknown；改为可验证的文件内容条件后才通过。此结果仍不等于目标级汇总交付。

最终隔离验证：两个 Area 中，项目任务和无业务目标的持续事项均由真实模型创建成果并经检查、复核达到 succeeded；持续事务仍启用，预算计数正确，项目成果下载内容匹配。仍需目标级汇总和交付、周期触发与补偿、上下文隔离、停止确认及正式界面后才可发布。
