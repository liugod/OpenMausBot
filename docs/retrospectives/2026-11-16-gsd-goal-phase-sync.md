# GSD 阶段同步三阶复盘

## 第一阶：结果

为 GSD 工作区建立稳定的任务与目标关联，运行中的本机服务读取 GSD 路线图并将阶段快照保存到目标数据库。聊天侧栏显示阶段进度；同步失败保留上一次成功快照。隔离服务测试覆盖创建与重试、路线图出现后的自动同步及目标接口读回，组件测试覆盖阶段展示。

## 第二阶：原因与边界

GSD 路线图和 OpenMaus 的目标验收不是同一个状态机。阶段完成仅表示 GSD 阶段记录，不自动改变目标状态、创建派工或代表验收通过。数据库迁移必须同时更新目标存储和预算存储的版本检查；测试 GSD 解析时应使用完整官方安装结果，而不是只复制其中一个目录。

## 第三阶：复用与改进

使用稳定任务 ID 和事务约束避免重复关联，明确指定已有目标时验证归属与关联冲突。周期同步应保留旧快照并暴露失败，不能把读取失败显示成零进度。涉及持久数据的部署先备份、以独立数据验证，重启后检查现有服务与技能读回。多工作流、跨机器运行和反向同步需要单独设计及验证。
